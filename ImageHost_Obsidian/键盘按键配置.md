# 键盘按键配置

> [!info]- 使用方法
> 1. 安装并启用 **Dataview**，在它的设置中打开 **Enable JavaScript Queries（启用 JavaScript 查询）**。
> 2. 用**阅读视图**打开本笔记，点击下方的层按钮切换六层。
> 3. 点击按键或旋钮，在面板下面填写快捷键、用途和软件，然后点击保存。
> 4. 展开“编辑本层名称与灯光颜色”，填写颜色说明和代表色，然后保存。
> 5. 不使用插件时，可以在笔记源文件中直接编辑下方的普通表格。
>
> 这是一份配置记录，不会向 VIA 或键盘写入改键和灯光设置。未确认的数据均留空。
> 键位按左至右、上至下编号 K01～K16；R1 为右侧左上旋钮，R2 为右上旋钮，R3 为下方大旋钮。
> 六层按 VIA 的习惯记为 0～5。旋钮不支持按压时，可在对应用途填写“不支持”。
